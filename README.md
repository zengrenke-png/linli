# 龙泉湾社区邻里食堂工作台

一个单文件、离线可用的社区食堂经营工作台示例。

## 功能

- 今日人数、营业额、采购成本和结余预测
- 每日实账：普通餐、老人餐补贴、外带收入及各项支出
- 区分“账面结余”和“不含未到账补贴的现金结余”
- 采购清单、菜单建议、员工执行清单和每日备注
- 不依赖 CDN、后端、账号或网络请求，数据只保存在浏览器本机

## 使用

直接双击 `index.html`，或在浏览器中打开它。每天收档后填写“每日实账”，点击“保存本日数据”。

示例数据仅用于演示，使用前请替换为店内实际价格、补贴口径和成本数据。

## 隐私

项目不上传数据。请不要在备注中填写身份证号、手机号、银行卡号或其他不必要的个人信息。
